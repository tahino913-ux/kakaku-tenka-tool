# 価格転嫁見積ツール

メーカーからの値上げに対して、**得意先ごとの「転嫁後 販売単価」を自動計算し、見積（Excel）を出力**するツールです。

「照合結果CSV（メーカーの値上げ品と販売実績を商品名で突き合わせた表）」を入力すると、
複数の転嫁ルールで新しい販売単価・粗利率を計算します。

---

## つかいかた（かんたん3ステップ）

1. **`input` フォルダ**に、照合結果CSV（例: `朝日食品容器_照合結果.csv`）を入れる
2. **`run.bat` をダブルクリック**する
3. **`output` フォルダ**に `○○_見積_日時.xlsx` ができる

> 初回のみ、下の「初回セットアップ」を実行してください。

---

## 初回セットアップ（このPCで初めて使うとき）

**Node.js をインストールするだけ**でOKです（https://nodejs.org/ja の「LTS」版）。
このツールは外部ライブラリを一切使っていないため、`npm install` は不要です。
別のPCでも、Node.js さえ入っていれば（Googleドライブ経由で）このフォルダをそのまま使えます。

---

## 入力CSV（照合結果）について

次の列があれば自動で認識します（**列名のゆれは吸収**します）:

| 必要な情報 | 認識する列名の例 |
|---|---|
| 現販売単価 | 現販売単価 / 現売単価 |
| 現仕入単価 | 現行仕入単価 / 仕入前回単価 |
| 新仕入単価 | 新仕入単価 / 仕入新単価 |
| 商品名 | 販売実績商品名 / 商品名 |
| 得意先名 | 得意先名 |
| 年間金額 | 年間金額 |

文字コードは UTF-8 / Shift-JIS を自動判定します。

## シミュレーション画面（`sim.bat`）

見積書を出す前に、**メーカーの改定額を入れたら転嫁後がどうなるか**をブラウザ上で試せます。

1. `input` フォルダに照合結果CSVを入れる
2. **`sim.bat` をダブルクリック**する（ブラウザが自動で開きます）
3. 画面で次を試せます:
   - **転嫁ルールの切替**（全体／得意先・商品ごと）
   - **改定後 仕入単価の上書き**（「もしこの額なら」を直接入力 → その行だけ即時再計算）
   - **端数処理**（円/銭・四捨五入/切上/切捨）
4. 上部のカードで **年間 仕入増・年間 増収・差引 粗利インパクト・平均粗利率** がまとめて見えます
5. 終了はサーバのウィンドウで **Ctrl+C**

> 年間数量は、CSVに「**年間数量**」列があれば実数（<b>実</b>）を、無ければ「年間金額÷現売単価」で推定（<b>推</b>）して年間影響額を計算します。

### 提出用 見積書の出力

シミュレーション画面で内容を決めたら、右上の **「この内容で見積書を出力」** ボタンを押すと、
**画面の設定（ルール・改定額の上書きなど）をそのまま反映**した見積書を**得意先ごとに1ファイル**で出力します。

- 出力先: `output/<元CSV名>_見積書_<日時>/見積_<得意先名>.xlsx`（実行ごとにフォルダ分け。出力後そのフォルダが自動で開きます）
- 体裁: タイトル・発行日・「○○ 御中」・自社情報・あいさつ文 ＋ 明細表（**No／商品名／現行単価／改定単価／値上額／値上率**）
- **得意先向けのため、仕入原価・粗利率は載せません。**
- 提出先（得意先）の無い「未一致」明細は自動で除外します。
- 自社名・住所・TEL・タイトル・あいさつ文・脚注は `config.js` の `company` / `quote` で編集できます（既定は「日野折箱店」＋住所等プレースホルダ。**住所と電話はご自身のものに書き換えてください**）。

このシミュレーションも外部ライブラリ不要（Node標準機能のみ）で、Googleドライブ上のフォルダから直接起動できます。

### 自社コスト（労務費・最低賃金）の上乗せ

メーカー値上げの転嫁に加えて、**自社の人件費・最低賃金の上昇分**も販売単価に上乗せできます。

- 画面の「**自社コスト上乗せ%**」に率を入れると、転嫁後単価へさらに `× (1 + 率%)` します（例: +3%）。
- **据え置き（keep_sell）の行には上乗せしません。**
- 既定値は `config.js` の `selfCostUplift.rate`。上昇率は公式「価格交渉支援ツール」等で確認して入力してください。
- 見積書（出力）にも、この上乗せ後の単価がそのまま反映されます。
- 損益パネルの「**自社コスト増/年(固定費)**」に年間増加額を入れると、固定費が「転嫁しない／転嫁する」の両方で増え、
  「上乗せで増えた人件費を回収できているか」を営業利益で判定できます。

### 全社 損益インパクト（変動損益計算書）

シミュレーション画面には「**全社 損益インパクト**」パネルがあり、選択中メーカーの値上げが
**会社全体の営業利益**にどう効くかを3列で並べて確認できます。

| | 現状 | 転嫁しない | 転嫁する（現設定） |
|---|--:|--:|--:|
| 純売上高 | 実績 | 実績 | 実績 + 年間増収 |
| 変動費合計 | 実績 | 実績 + 年間仕入増 | 実績 + 年間仕入増 |
| 限界利益 | 売上−変動費 | ↓仕入増の分減 | 増収−仕入増の分動く |
| 固定費合計 | 実績 | 実績 | 実績 |
| 営業利益 | 限界利益−固定費 | … | … |

- **データの置き方:** プロジェクト直下に `損益.csv`（2列 `項目,金額`）を置くと自動読込します。
  列ラベルのゆれ（純売上高/売上高、変動費合計、固定費合計、人件費＋他の固定費 など）は吸収します。
  ```
  項目,金額（千円）
  純売上高,97220
  変動費合計,70975
  人件費,13978
  他の固定費,14088
  ```
  ※ `固定費合計` が無ければ「人件費 ＋ 他の固定費」で計算します。
- **単位:** パネル右上の「単位」（円／千円／百万円）で扱います（既定: 千円）。
- ファイルが無くても、画面上で純売上高・変動費・固定費を**手入力して試算**できます。

## 計算ルールの変更（`config.js`）

`config.js` を編集すると、転嫁後の販売単価の決め方を変えられます。

| ルール | 内容 |
|---|---|
| `add_increase` | 値上げ額をそのまま上乗せ（利益額キープ）※既定 |
| `keep_margin_rate` | 現在の粗利率を維持して再計算 |
| `markup` | 新仕入 × 掛率（factor） |
| `keep_sell` | 値上げしない（据え置き） |

得意先・商品・メーカー単位で**ルールを使い分ける**設定もできます（`config.js` の例を参照）。

---

## 出力（Excel）の内容

得意先名・商品・現/新仕入・値上額/率・現販売単価・現粗利率・**転嫁後 販売単価**・**転嫁後 粗利率**・
適用ルール・推定年間数量・年間金額・値上げ年間影響額・照合 を1行ずつ出力します。

## メーカー見積の取り込み → 照合（照合結果CSVを自動で作る）

メーカー（問屋）からの値上げ表を、販売実績と突き合わせて「照合結果CSV」を自動作成できます。

1. **メーカー見積の Excel(.xlsx) を用意**（複数シート＝複数メーカーでもOK。例：中東の `日野折箱店様（容器メーカー）.xlsx` はエフピコ／中央化学／福助の3シート）
2. 取り込み方法は2通り：
   - **`取込.bat` にドラッグ＆ドロップ** → `maker_quotes/` にメーカー別CSVが作られる
   - または **`maker_quotes/` フォルダに .xlsx を置く**だけ（`照合.bat` 実行時に自動で取り込まれる）
   - ※ PDFや表の貼り付けで取り込みたいときは `sim.bat` → 右上「メーカー見積を取り込む」(/import) を使う
3. **`照合.bat` をダブルクリック** → 販売実績と照合し、`input/` に `<メーカー>_照合結果_<日時>.csv` を出力
4. あとは `sim.bat` で照合結果を選び、内容を確認して見積書を出力

> 列（商品名・現単価・新単価・切替日）は見出しから自動判別します。直近1年の販売実績に無い品は「休眠」として見積から自動で外れます（売っていない品は転嫁対象外）。
