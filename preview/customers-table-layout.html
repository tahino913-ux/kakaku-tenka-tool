コンパクト案についての所感
  • 目的に合っている … 得意先ページ＝「転嫁できているか」の確認が主。現単価を括弧に下げるのは合理的です。
  • 比較が一目 … 仕入改定 31% と 売価改定 33.6% を横に並べると、粗利が維持・改善されているかすぐ分かります。
  • 商品名 … 短縮せず、これまでどおり正式名をそのまま表示（リンクは照合画面へ）。
  • 追加提案 … 売価改定 < 仕入改定 の行に「要確認」バッジ（上の3行目例）。据置・手入力で意図的な場合は問題なし。
