Claude Code モード・機能 一覧

価格転嫁見積ツール 作業メモ ／ 2026-05-30 時点 ／ 使用モデル：Claude Opus 4.8（1M コンテキスト・最新）

1. パーミッション（権限）モード ― Shift + Tab で切替

作業の進め方を変えるモードです。今どのモードかは画面下のステータスバーに表示されます。

モード内容向いている場面
通常モードファイル編集やコマンド実行のたびに「やっていい？」と確認する普段使い（安全）
自動承認モード
(auto-accept edits)		ファイル編集をいちいち確認せず自動で進める安心して任せられる作業を速く回したいとき
プランモード
(Plan mode)		実際には変更せず、まず計画だけ立てて見せる。OKしたら実行大きな変更の前に方針を確認したいとき

2. ファストモード ― /fast

Opus の賢さはそのままで、出力（返答）を速くするモードです。

  • 賢さは落ちません。小さいモデルに切り替わるのではなく、Opus のまま速くなります。
  • 対応モデル：Opus 4.8 / 4.7 / 4.6
  • /fast と打つとオン／オフ切替

3. 拡張思考（じっくり考える）

むずかしい問題のとき、Claude が内部で深く考えてから答えます。複雑な照合ロジックの修正などで自動的に働きます。

モード以外の便利機能

機能使い方何ができる
スラッシュコマンド/ を打つと一覧/code-review（コードの問題チェック）、/security-review、/config（設定）など
「!」で直接コマンド実行! コマンドログインなど、自分でターミナル操作したいとき
メモリ（記憶）「これ覚えておいて」あなたの好みや方針を覚えて次回以降に反映
CLAUDE.md自動で読み込みこのツールの引き継ぎメモ（毎回起動時に読む）
使えるアプリ―ターミナル ／ デスクトップアプリ(Mac・Win) ／ Web(claude.ai/code) ／ VS Code・JetBrains 拡張
💡 あなたの場合のおすすめ
  • 大きな変更前 → Shift+Tab でプランモードにして方針を確認 → OKなら実行
  • 細かい修正をテンポよく → /fast（賢さ落ちないので常時ONでも可）
  • コードの不具合チェック → /code-review
