# 画面の役割分担（確定方針）

## 各画面の役割

| 画面 | パス | やること | やらないこと |
|------|------|----------|--------------|
| **メイン** | `/` sim | 照合・紐付け確認、仕入コスト、全体損益、休眠救済 | 転嫁ルール編集、見積書発行、得意先別単価調整 |
| **得意先別** | `/customers` | 転嫁ルール・行ルール・手入力売価・実施日・**見積発行** | 照合エンジン設定 |
| **取込** | `/import` | メーカー見積の貼付・ファイル取込・保存 | 照合実行（保存後に自動照合は可） |
| **コード化** | `/cdlink` | 商品名3（メーカー品番）候補の確定/却下 | 価格計算 |
| **実施日カレンダー** | sim内 | 実施日横断ビュー、基幹CSV（単価履歴・仕入原価）DL | 見積書の新規作成 |

## UI改修時の禁止・注意

- メイン表に **売価・粗利・行ルール・見積出力ボタン** を復活させない（過去に撤去済み・合意済み）
- メイン＝**照合・コスト専用**、価格・見積は得意先別
- 見積書作成の導線は `/customers`（メインはリンク・案内のみ）
- 設定の全体方針は **⚙設定モーダル**（メイン上部の旧バーは廃止済み）

## データの流れ

```
/import または maker_quotes/ → 照合(shogo) → input/*.csv
→ sim で確認・紐付け → /customers で単価決定・発行 → output/
```

## 問屋経由の見積

エフピコ・中央化学・CP化成・リスパック・青葉・伊藤敏等は **朝日食品容器経由**で `makerChannel` 統合。別仕入先の照合CSVを増やさない。
